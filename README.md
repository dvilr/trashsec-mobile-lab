# TrashSec Mobile Lab

Turning a budget Moto G 2025 into a portable Linux, networking, Bluetooth, GPS, and field documentation lab.

## Purpose

This project documents how weak hardware can still be useful for IT, networking, cybersecurity learning, field notes, asset tracking, and remote administration.

## Device

- Phone: Moto G 2025
- OS: Android
- Environment: Termux

## Tools

- Termux
- Git
- Python
- OpenSSH
- Nmap
- Nano
- tmux
- Termux:API

## Legal Scope

This project is only for owned devices, personal lab work, and networks where I have permission.

## Privacy and Sanitization

This repository is public-safe by default. Any screenshots, logs, scan outputs, GPS data, or device inventories are sanitized before publishing.

Sanitized information includes:

- MAC addresses
- Wi-Fi SSIDs
- public IP addresses
- router serial numbers
- exact GPS locations
- personal device names
- emails, usernames, tokens, and passwords
- screenshots with account or notification data

All examples use redacted values or lab-safe sample data.
